The page reads each headline with an OCR engine running inside your browser, then identifies the language with statistical n-gram models — real language detection, not a word list tied to one campaign. Two things make it accurate on short headlines: words that repeat across the whole batch are the campaign name, so they are ignored; and because a campaign set carries one image per market, each market code is handed out once. Anything it is not confident about is flagged, and the text it read is shown next to every file so you can check it. The engine is about 20 MB and loads the first time you press Detect languages; after that your browser caches it. Nothing is ever uploaded. Re-encoding drops EXIF metadata and converts everything to JPEG on a white background.
